# Giverny 品牌设计

Giverny（吉维尼）致敬莫奈晚年居住的法国小镇。莫奈最著名的作品之一是《睡莲》，因此 Giverny 的四季配色、空间氛围和品牌语气，都从睡莲池的水面、光影与花园生长中获得灵感。

> **让创作在自己的花园里生长。**

## 品牌感受

Giverny 不是把工作台装饰成一座花园，而是希望让原本枯燥的任务、工时和交付记录，拥有一点光影、色彩和生长感：

- 工作是画布。
- 任务是正在生长的作品。
- 进展是落在水面上的新色彩。
- 交付是花园里完成的一处风景。

## 状态语言

| 工作状态 | Giverny 文案 |
| --- | --- |
| 没有任务 | 花园很安静：等待一项新的创作在这里生长 |
| 没有进展 | 等待新的色彩落入花园 |
| 进行中的任务 | 新的色彩正在水面上展开 |
| 已交付但未验收 | 作品已经呈现，等待最后的注视 |
| 已验收 | 这一笔已经落定，花园里留下了新的风景 |
| 已完成 | 这幅作品已经完成。它曾经在这里生长，也终于在这里绽放 |

这些文案只用于空状态、时间线、加载和完成反馈。任务名称、工时、金额、验收日期等业务信息仍然保持直接、清晰、可核对。

## 吉维尼模式

吉维尼模式使用来自莫奈《睡莲》的低饱和季节色彩，让工作空间随着四季变化：

- 春：嫩芽初生的浅绿
- 夏：睡莲池的清水青
- 秋：花园与晚霞的暖色
- 冬：雾气中的水面蓝

## 登录页

登录页是进入 Giverny 的第一处场景。它使用原创的莫奈花园氛围图作为整页背景，包含睡莲池、树影、花园和水面光线；水面会出现明显但克制的波纹，花园光影和枝叶会随微风缓慢变化。

登录面板保持清晰、轻量，不让动画遮挡邮箱、密码和登录操作。支持减少动态效果的系统偏好，低性能设备和移动端会降低动画强度。

## 设计原则

品牌感通过色彩、文案、光影、节奏和任务生命周期自然渗透，不依赖大量睡莲插画、花瓣、渐变或装饰性卡片。Giverny 首先是一套可靠的工作与结算工具，然后才是一座让创作更有温度的花园。
