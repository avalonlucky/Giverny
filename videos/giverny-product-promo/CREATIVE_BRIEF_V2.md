# Giverny 品牌产品片 V2 · 创意简报

## 策略句

**这支片子要告诉公司、兼职团队、设计服务负责人和独立创作者：Giverny 把原本分散、容易消失的工作投入，变成一条看得见、说得清、结得明白的成果链路，同时让可靠的工作工具保留艺术与生长的温度。**

## 不是在拍什么

- 不是普通项目管理软件的功能巡礼。
- 不是用大标题遮住产品界面的 SaaS 模板片。
- 不是把莫奈、睡莲和花园当成装饰素材反复堆叠。
- 不是为了显得“高级”而增加无意义转场、3D 卡片或炫技粒子。

## 真正要回答的问题

1. **为什么需要 Giverny？** 需求、工时、文件、验收和对账长期散落在不同工具里，创作者的真实投入很难被完整看见。
2. **Giverny 是什么？** 它不是泛用看板，而是把任务流转、工时证据、文件交付、验收与结算串成一条可追溯链路的工作台。
3. **它带来什么结果？** 创作者不用月底重新证明自己做过什么；负责人和合作伙伴也能直接看懂做了什么、花了多久、交付了什么、为什么结算。
4. **Agent 为什么不同？** 爱丽丝工作在任务、文件、进展和企业记忆的真实上下文里；她会分析、规划、发现风险，写入前确认，结果可验真。
5. **品牌为什么叫 Giverny？** 它致敬莫奈晚年生活与创作的吉维尼。品牌相信产品不只解决工作，还应该让创作保留艺术、色彩和生长的乐趣。

## 核心品牌命题

> 可靠的工具，让创作留下证据；有温度的空间，让创作继续生长。

品牌意象只承担三项工作：

- 开场提出“创作投入不该消失”。
- 中段把严谨的工作证据与人的创作感连接起来。
- 结尾解释“让创作在自己的花园里生长”。

其余时间由真实产品 UI、真实操作和真实 demo 数据主导。

## 形式与长度

- **成片长度：** 65 秒。
- **画幅：** 1920×1080，30fps。
- **类型：** 品牌叙事驱动的真实产品演示片。
- **节奏：** `慢建立 → 清晰推进 → 证据累积 → Agent 高点 → 安静收束`。
- **旁白：** 中文主版；英文版使用独立旁白与字幕，不改变镜头节奏。
- **国际化：** 画面叙事尽量依靠操作、图形关系和短句；所有宣传文案集中在语言字典中。中文、英文先交付，日语文案保留扩展位。

## 画面原则

- 每个镜头只证明一个核心价值。
- 真实 UI 在产品段落占画面 80% 以上，字幕避开关键操作区域。
- 不用浮动数据卡重新“画一遍”已有界面；镜头直接移动到真实数据与真实交互上。
- 产品动画来自真实动作：新建、输入、记录进展、添加工时、上传文件、验收核对、生成回单、打开分享页、Agent 执行。
- 品牌动画来自光、水面、季节与纸张节奏，克制使用。
- 不展示正式工作区数据；所有录制只进入 `demo@mayeai.com` 演示空间。
- 不编造金额、任务数或 Agent 结果；画面只使用录制当时真实 demo 返回值。

## 声音方向

- 不是持续轰鸣的科技电子乐，而是有空间感的暖色氛围音乐。
- 产品操作使用少量真实感 SFX：键入、状态确认、纸张翻页、验收落定、回单生成。
- Agent 段落增加轻微节奏层，但不能变成“AI 炫技”音乐。
- 品牌结尾留下约 1.2 秒呼吸空间。

## 审核门槛

本阶段只审核：核心命题、旁白、镜头顺序和每个镜头的叙事职责。未经确认，不进入新一轮 UI 录制、配音、音乐选择或高质量渲染。
